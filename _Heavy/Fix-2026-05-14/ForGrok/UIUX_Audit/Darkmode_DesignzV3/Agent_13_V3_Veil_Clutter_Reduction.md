# Agent 13 — Glassmorphism Restraint Specialist — Phase 1.1 Clutter Reduction Recommendations

**Agent:** 13 — Glassmorphism Restraint Specialist  
**Date:** 2026-05-18  
**Reference Screenshot Analyzed:** Current dense task execution view  
**Target Reduction:** 70%+ while keeping tasteful, contextual glass

---

## 1. Current Clutter Diagnosis

The current view sometimes overuses visual treatments (glass, shadows, borders, teal accents) in places that add noise rather than clarity.

---

## 2. 70% Reduction Strategy

### 2.1 Move to Right-Side Veil Drawer
The Veil Drawer is the **primary and richest** place for glassmorphism in the V3 system. This is where the beautiful frosted glass with strong borders lives.

### 2.2 Move to Hover Cards / Previews
Use very light, fast glass treatment on hover cards — not as heavy as the main Veil.

### 2.3 Move to Modals
Modals can use slightly stronger glass treatment since they are temporary and focused.

### 2.4 Remove or Collapse Entirely
Remove decorative glass, heavy shadows, or unnecessary borders from the default list view. The list should feel calm and minimal.

### 2.5 React Component Opportunities
- `VeilGlassCard` (rich treatment, only for use inside Veil and modals)
- `MinimalCard` (flat, low-visual-weight for list items)
- Clear token separation between "Veil Glass" and "Minimal Dark"

---

## 3. Impact on Default View

By reserving rich glassmorphism for the Veil and modals, the default list becomes much calmer and easier to scan. This directly supports the 70% reduction goal.

---

## 4. Glassmorphism Application (Veil Glass Rules)

**Core rule:** Glass is contextual and purposeful.
- Rich, frosted, luminous glass → Veil Drawer + modals
- Very subtle or no glass → Default list view
- The glass should feel like a "veil" that appears when you want more depth, not decoration everywhere.

This matches the new V3 direction (dark + minimal + contextual glass).

---

## 5. Risks & Trade-offs

- Risk: Some designers may want more glass on the list → Strong guidelines + Agent 13 + 14 review for exceptions
- Benefit: The glass feels special and meaningful when it appears (in the Veil), rather than being background noise

---

## 6. Dependencies on Other Agents

- Agent 03: Veil must be the hero surface for glass
- Agent 06: Minimal list must stay minimal (no decorative glass)
- Agent 14: Consistent application across all surfaces

---

## 7. Measurement & Validation Approach

- Visual audit: Count how many surfaces use rich glass only in the Veil vs elsewhere
- User perception: "Does the glass feel meaningful or just decorative?"

---

## 8. Phase 1.1 Exit Recommendation

Publish the official **"V3 Veil Glass Usage Guidelines"** so everyone knows exactly when and how to apply glassmorphism in the new minimal system.
