## Notes
- All main feature routes use `<FeatureRouteGuard featureId="...">` for permission gating.
- Many use `<RoleGate denyTrainer>` to restrict trainers.
- Heavy use of lazy() + Suspense for code-splitting (see top of App.tsx).
- MobileIncidentExecutionPage handles multiple sub-routes via `stage` prop.
- Onboarding V2 uses nested <Route> inside OnboardingV2Layout.
- CommandCenterLayout (src/policy/components/CommandCenterLayout.tsx) provides the shared shell/sidebar/header for most pages.
