## Summary of Cross-Cutting Patterns Observed Across the 5 Pages
- **uiStore** (shell theme) is used by Dashboard, Library, MasterCalendar.
- **regulatoryExecutionStore** + **autogenStore** are shared heavily by Dashboard, Calendar, Evidence (core execution surfaces).
- **pm/** layer (taskProjection, sprint stores, selectedTaskStore) appears in Calendar + Evidence.
- **components/ui/** primitives are ubiquitous (EmptyState, drawers, banners).
- **data/regulatoryEvents** is foundational data source for 4/5 pages.
- PolicyDetailPage is the outlier — deliberately thin delegation layer.
- MasterCalendarPage has the broadest dependency fan-out (regulatory + pm + ces + calendarSync).
- EvidenceCenterPage has the most "service-like" dependencies (evidence runtime, artifacts, external API config).
- Many pages use generated .generated.ts data files for seed/taxonomy content.
