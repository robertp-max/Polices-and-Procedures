# Supervised Visitation & Clinical Oversight Matrix

_Master Correction Prompt §13. Status: **REFERENCE DOCUMENTED; dedicated UI surface not yet built** (competency/supervised-practice items appear today in the Competencies workspace; the role-specific cadence matrix below is the spec for the pending UI)._

## HHA (42 CFR 484.80)

- **Patient also receives skilled services:** RN supervisory assessment **at least every 14
  days**; aide need not be present for the routine assessment; limited virtual option per
  current rule; **annual on-site direct observation** of each aide performing care.
- **Aide-only patient:** RN **on-site assessment every 60 days**; **semiannual on-site direct
  observation** of the aide performing care.
- **Deficiency path:** concern identified → on-site observation → retraining → competency
  re-evaluation → follow-up/closure.
- **In-service:** **12 hours per 12-month period** (484.80(d)) — surfaced as a separate clock
  in the rebuilt Annual page (implemented).
- Display as **separate clocks** (patient supervisory assessment / direct observation /
  in-service hours / competency-remediation) — do not merge.

## LVN

RN oversight per current agency policy and California scope; documentation/co-sign review
where required; assignment-specific observation; escalation/retraining. **LVN may not perform
the initial comprehensive assessment / OASIS.** No cadence is invented where policy is silent.

## PTA / COTA

Supervisor, visit/reassessment deadline, visit-count trigger (where applicable), documentation
review, current status — per the current PT/OT supervisory & reassessment cadence.

## RN / PT / OT / SLP / MSW / DON

Initial supervised practice, record review, skill checkoff, annual/triggered competency,
leadership review, role-specific advanced training. No patient-level data / PHI.

## OIG/SAM

Monthly exclusion status is HR/Compliance-owned; the employee sees **status only** (Cleared /
Under review / Action required / Waiting on HR / Not applicable), never the raw screening
result.
