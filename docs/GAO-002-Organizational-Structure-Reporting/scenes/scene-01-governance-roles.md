### Interaction Pattern
1. Map loads with pulsing hotspots (0 / 4 unlocked).
2. Click hotspot → unlock role card (Field Notes style explanation + citation).
3. Challenge node: scenario decision (4 options). Wrong → corrective feedback + retry. Correct → advance.
4. Progress updates. When all unlocked + challenge complete → scene complete.
