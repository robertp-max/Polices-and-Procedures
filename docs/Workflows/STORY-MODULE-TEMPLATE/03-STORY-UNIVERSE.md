# Care Indeed Story Universe — shared canon registry

All story-driven modules share one fictional world. Reusing established characters is how the 42 modules feel like one program instead of 42 disconnected skits — and how retention devices (a preceptor's catchphrase, a familiar patient) work *across* modules, not just within one. Story-bible authors read this file first; every module that ships new canon appends it here in the same effort.

## Rules

1. **Reuse before inventing.** If an established character fits the scene's role, use them. Introduce a new character only when no established one plausibly fits, and give them a full character-sheet entry here.
2. **Protagonist selection by audience.** `roles: 'ALL'` modules (the GAO phase) follow the shared new-hire protagonist. Role-track modules (ADM/DON/RN/HHA/…) use a protagonist from that track — a new hire *in that role* — so scenarios exercise that role's actual decisions. Established cast may cross over (Dana Whitfield can brief anyone).
3. **Timeline discipline.** State each module's position on the character's timeline (GAO-001 = Alex's first week). Later modules may be later weeks; don't contradict established sequence. GAO modules are Days 1–5 in-catalog — multiple GAO modules can share the same story week from different angles, but check this registry for collisions.
4. **Composite patients only.** Patients are fictional composites, never tied to a real record, and always depicted with dignity (invariants §6). A patient may recur across modules if their clinical picture fits.
5. **Continuity props and phrases are canon.** Once a prop (the badge, the field notebook) or a signature phrase ("when in doubt, report") is established, later modules reference the *same* one — never re-introduce or re-shoot it.
6. **No villains.** Ambiguity drives scenarios; family members, colleagues, and patients are never written as adversaries or resolved as guilty/innocent.
