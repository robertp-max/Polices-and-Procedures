# Skeleton — design/01-story-bible.md

**Purpose:** the module's narrative canon — who, when, and in what voice. Everything module-specific about story lives here; everything universal about voice lives in invariants §13.
**Exemplar:** `docs/GAO-001-A-New-Journey/design/01-story-bible.md`
**Inputs:** recon/content-inventory, `03-STORY-UNIVERSE.md` (binding — reuse before inventing), invariants §6/§13.

## Required sections

1. **Protagonist character sheet** — reused from the universe registry (state which weeks/timeline slot this module occupies) or, for a first-of-track module, a new full sheet: background, personality, anxieties, confidences, growth arc across this module. The arc names its endpoints (GAO-001's: *competent outsider → oriented insider*).
2. **Supporting cast** — every named character with role, canon facts, and universe status (established / new — new ones get flagged for the registry). Patients are composites (invariants §6).
3. **Story structure — scenes mapped to story time** — table: scene # / story time / scene title (source page mapped) / one-line story beat / emotional note. Must map 1:1 to the source page structure.
4. **Continuity devices** — the props, message channels, signature phrases, and cross-scene callbacks this module uses; which are inherited from the universe registry vs. newly established.
5. **Voice & tone application** — module-specific do/don't lists applying invariants §13 to this subject matter (a harassment module and a benefits module need different registers — say how).
6. **Story-instruction seam plan** — who voices instruction in this module (the preceptor? a specialist character?) and the bridge pattern per scene type.

## Done when

- Every scene has a story beat consistent with the universe timeline.
- No cast contradicts the registry; new canon is explicitly listed for appending.
- A storyboard author could write any scene's narration in a voice indistinguishable from the others.
