# Skeleton — 00-OVERVIEW.md (master synthesis)

**Purpose:** the one document a stakeholder reads. Everything else is linked detail.
**Exemplar:** `docs/GAO-001-A-New-Journey/00-OVERVIEW.md`
**Written last** (Phase 6), after audits are resolved.

## Required sections

1. **What this package is** — module identity line (ID, title, subtitle, status, date); what was preserved (canonical identity per invariants §1, stated concretely for this module); what changed (delivery only); the package map table.
2. **The story in one paragraph** — the whole arc, cast bolded, ending with the voice rule.
3. **Headline design decisions** — the template-per-scene table; the redundancy contract in two sentences; anything decided that a stakeholder would want to know first.
4. **Narration system summary** — tiers, coverage accounting, storage, delivery recommendation, word count of drafted scripts.
5. **Compliance guardrails (binding)** — the module's instantiated guardrails: wording, state separation, citation map summary, verbatim sentences.
6. **Learning & assessment alignment** — the alignment map summary and pacing total.
7. **What the audits found and how it was resolved** — highlights with severity tags; state plainly that coverage/continuity findings were applied and feasibility findings became tickets.
8. **Implementation plan** — pre-existing live defects (spun off separately), platform blockers, per-scene build order & effort, handoff split (architecture vs. mechanical).
9. **Decisions made during synthesis (flip-able)** — every judgment call made without stakeholder input, each with the alternative and what flipping costs. Never bury these.
10. **Open items for stakeholders** — the short list requiring human decision, each pointing at its section.

## Done when

A stakeholder who reads only this file knows every decision made on their behalf, every open question, and what happens next — and nothing in it contradicts the detail documents.
