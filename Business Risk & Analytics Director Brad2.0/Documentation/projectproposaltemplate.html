Google Drive for Desktop

Research Phase

Executive Summary: Google Drive for desktop unifies the file management experience, replacing the legacy "Drive File Stream" and "Backup and Sync" clients. For Care Indeed, this tool is the primary bridge between cloud-based collaboration and legacy desktop workflows (Word, Excel, PDF forms). The critical decision point for Healthcare IT is configuring the tool to prevent the mass downloading of PHI to local unmanaged endpoints.

Core Architecture: Stream vs. Mirror

This configuration is the most critical decision for Care Indeed's HIPAA compliance.

RECOMMENDED

S
Stream Files

Creates a virtual drive (e.g., G:). Files exist primarily in the cloud and are downloaded temporarily only when opened.

  • + Minimal local disk footprint
  • + Drastically reduces PHI exposure on endpoints
  • + Instant access to massive Shared Drives
  • - Requires internet (unless manually cached)

M
Mirror Files

Traditional syncing approach. Duplicates all selected cloud content directly to the local hard drive.

  • - Consumes massive local storage
  • - High risk of PHI loss on stolen/lost devices
  • + Files always available offline
  • + Native OS search indexes everything

HIPAA & Endpoint Security

Implementing Drive for desktop creates a bridge between the cloud and the local machine. Consequently, the endpoint device becomes part of the compliance perimeter.

ENC

1. Local Cache Encryption

Drive for desktop maintains a content cache (metadata and offline files) in %LOCALAPPDATA%. While Drive encrypts this cache, it decrypts seamlessly for the logged-in OS user.

Defense in Depth: Do not rely solely on Google's app encryption. BitLocker (Windows) or FileVault (macOS) must be active on the host machine to secure PHI at rest.
DEV

2. Device Restrictions

By default, users can download the Drive client onto personal, unmanaged home computers and sync corporate data.

Critical Action: Implement 'Endpoint Verification' or Context-Aware Access in Google Workspace to block desktop client authentication on non-company devices.
USB

3. External Media Risks

Drive for desktop includes a consumer feature that prompts users to back up attached USB sticks or external hard drives automatically.

Admin Control: Disable "External Media Backup" via Workspace Admin Policies to prevent rogue data ingestion or extraction.

Staff FAQ

Plain-english explanations for non-technical clinical and administrative staff.

Is 'Drive for Desktop' the same as 'Google Drive' on the web?

Mostly, but it acts like a physical hard drive on your computer (usually the G: drive). You can drag, drop, and double-click files to open them in Word or Adobe just like normal Windows files.

If I lose internet, can I see my patient files?

By default, no. If you know you are visiting an area with bad cell signal, you must right-click the specific files or folders beforehand and select "Available Offline".

Does this save files locally to my laptop?

In our default "Stream" mode, no. It only temporarily caches what you are actively working on. This is to protect patient data if your laptop is lost or stolen.

Can I save a file to the G: drive if I am offline?

Yes. If you edit an offline file, or save a new file to the G: drive while offline, it sits in a queue. It will automatically upload to the cloud the moment you reconnect to WiFi.
