# KB-002 — How to Complete an Execution Unit

**Audience:** Anyone assigned an execution unit. **Time to read:** 3 minutes.

## Step-by-step

1. Open the **Sprint Board**.
2. Find the card assigned to you. Click to open the **detail drawer**.
3. Read the **Workflow Phase** badge (top of drawer):
   - **Preparation** → assemble inputs (sample list, prior period data).
   - **Documentation** → fill the required forms.
   - **Review** → confirm prior output is correct.
   - **Signature** → click **Send for Signature**.
   - **Audit** → upload final evidence.
4. Complete every item in the **Checklist** section.
5. Click **Mark Complete**.
6. The system validates and advances the unit. If something is missing,
   you'll see a red banner — see [KB-003](KB-003-Cannot-Mark-Complete.md).

## What "complete" requires

A unit is complete only when **all three** are true:

- Every form in `Required Forms` is saved.
- Every signer in `Required Signers` has signed (in the signature phase).
- The final artifact is in the Evidence Center, tagged with the unit's
  `event_id`, `workflow_id`, and `policy_id`.

## Tips

- Use the **Save Draft** button on long forms — your work is preserved if
  you log out.
- The drawer remembers your last open tab per unit.
- Add a comment in **Notes** if you want to leave context for the next
  phase owner.
