# API: PM (Project Management) (`/api/pm`)

**Mount Path:** `/api/pm`  
**File:** `server/routes/pm.ts`  
**Auth Required:** Yes (all endpoints)

---

## Overview

The PM API manages task overlays, personal task lists, task watchers, and the notification inbox. It supports the task management layer that sits on top of compliance execution.

---

## Endpoints

---

### GET `/api/pm/overlays/:taskId`

**Purpose:** Retrieve the overlay (annotations, notes, priority overrides) for a specific task.  
**Auth Required:** Yes  

**Response (200):**
```json
{
  "taskId": "string",
  "notes": "string",
  "priorityOverride": "critical | high | medium | low | null",
  "tags": ["string"],
  "updatedAt": "2026-04-29T10:00:00Z"
}
```

---

### PUT `/api/pm/overlays/:taskId`

**Purpose:** Update or create the overlay for a task.  
**Auth Required:** Yes  

**Request Body:**
```json
{
  "notes": "string",
  "priorityOverride": "high",
  "tags": ["blocker", "needs-review"]
}
```

**Response (200):** Updated overlay object.

---

### DELETE `/api/pm/overlays/:taskId`

**Purpose:** Remove overlay annotations from a task.  
**Auth Required:** Yes (task owner or manager)  

**Response (200):** `{ "message": "Overlay deleted" }`

---

### GET `/api/pm/personal`

**Purpose:** Retrieve the current user's personal task list.  
**Auth Required:** Yes  

**Response (200):**
```json
[
  {
    "id": "string",
    "title": "string",
    "description": "string",
    "status": "not_started | in_progress | completed | cancelled",
    "priority": "critical | high | medium | low",
    "dueDate": "2026-05-01",
    "createdAt": "2026-04-29T10:00:00Z"
  }
]
```

---

### POST `/api/pm/personal`

**Purpose:** Create a new personal task.  
**Auth Required:** Yes  

**Request Body:**
```json
{
  "title": "string",
  "description": "string",
  "priority": "medium",
  "dueDate": "2026-05-01"
}
```

**Response (201):** Created task object.

---

### PATCH `/api/pm/personal/:taskId`

**Purpose:** Update a personal task (status, priority, due date, etc.).  
**Auth Required:** Yes (task owner only)  

**Request Body:** Partial task fields.  
**Response (200):** Updated task object.

---

### DELETE `/api/pm/personal/:taskId`

**Purpose:** Delete a personal task.  
**Auth Required:** Yes (task owner only)  

**Response (200):** `{ "message": "Task deleted" }`

---

### GET `/api/pm/notifications`

**Purpose:** Retrieve the current user's notification inbox.  
**Auth Required:** Yes  

**Response (200):**
```json
[
  {
    "id": "string",
    "type": "task_assigned | approval_required | signature_required | event_overdue",
    "title": "string",
    "message": "string",
    "read": false,
    "createdAt": "2026-04-29T10:00:00Z",
    "actionUrl": "/calendar?event=governing_body_meeting-20260514-01"
  }
]
```

---

### POST `/api/pm/notifications/ack`

**Purpose:** Mark a notification as read.  
**Auth Required:** Yes  

**Request Body:**
```json
{
  "notificationId": "string"
}
```

**Response (200):** Updated notification object with `read: true`.

---

### GET `/api/pm/watchers`

**Purpose:** Retrieve tasks the current user is watching.  
**Auth Required:** Yes  

**Response (200):** Array of task objects the user is watching.

---

### POST `/api/pm/watchers`

**Purpose:** Add a watcher to a task.  
**Auth Required:** Yes  

**Request Body:**
```json
{
  "taskId": "string",
  "userId": "string"
}
```

---

### DELETE `/api/pm/watchers`

**Purpose:** Remove a watcher from a task.  
**Auth Required:** Yes  

**Request Body:**
```json
{
  "taskId": "string",
  "userId": "string"
}
```

---

## Notes

- Personal tasks are independent of compliance events — they are self-managed by the user
- Overlays are an annotation layer on top of compliance tasks — they do not affect the compliance record
- Notifications are generated by the compliance engine and the eCIgn system; this API provides the inbox interface
