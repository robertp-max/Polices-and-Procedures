# Evidence Center — How-To Guide

**Article:** 02-How-To  
**Page:** Evidence Center (`/evidence`)

---

## Uploading Evidence

### Step 1: Navigate to the Evidence Center
Go to `/evidence` or click **Evidence Center** in the left navigation.

### Step 2: Select the Evidence Kind
From the **Evidence Kind** dropdown, select the type of document you are uploading:
- Meeting Minutes
- Attendance Roster
- Signed Form
- Training Record
- etc.

### Step 3: Link to an Event
From the **Event Selector** dropdown, select the compliance event this evidence supports.
- Type the event name or scroll through the list
- If you know the `event_id`, you can type it directly
- **Important:** Linking to the wrong event means the evidence will not count for the correct compliance obligation

### Step 4: Upload the File
- Drag the file into the upload zone, or click to browse
- Allowed formats: PDF, PNG, JPG, DOC, DOCX
- Maximum file size: 25MB
- The file will appear in the "Staged" section after upload

### Step 5: Submit for Review
- Click the **Submit for Review** button next to your uploaded document
- The document moves to "Submitted" status
- Your manager will receive a notification to review it

## Reviewing and Accepting Evidence (Manager/Admin)

### Finding pending evidence
1. Go to `/evidence`
2. Apply the filter: Status = "Submitted"
3. All documents awaiting review will appear

### Reviewing a document
1. Click the document row to open the Review Panel on the right
2. Click the document name to open or download it
3. Read/view the document carefully
4. Confirm it matches the expected evidence for the linked event

### Accepting evidence
1. In the Review Panel, click **Accept**
2. The document transitions to `accepted` and becomes immutable
3. The linked event's completion status updates to reflect the accepted evidence

### Rejecting evidence
1. In the Review Panel, click **Reject**
2. Enter a reason for rejection (required)
3. The uploader receives a notification with the rejection reason
4. The uploader must upload a corrected document

---

## Downloading Evidence

1. Find the evidence document in the table
2. Click the **Download** icon in the row
3. The file will download to your computer

---

## Viewing Evidence for a Specific Event

1. In the Filter Bar, select the event from the **Event Filter**
2. All evidence documents linked to that event will appear
3. You can see which are accepted, pending, or rejected

---

## Common Questions

**I uploaded evidence but it's linked to the wrong event — can I change it?**  
No. Once submitted, the event link cannot be changed. Reject the document (if you are a manager) and have the uploader re-upload it with the correct event selected.

**Why is my accepted evidence still not completing the event?**  
Accepted evidence is one of four requirements for event completion. The event also requires: all workflow steps complete, all approvals granted, and administrator certification. Check the Event Workspace for what else is needed.
