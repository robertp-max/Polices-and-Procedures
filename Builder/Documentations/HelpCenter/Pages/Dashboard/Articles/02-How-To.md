## Reading the Dashboard

### Step 1: Check the KPI tiles

When you log in, the first thing to review is the row of KPI tiles at the top of the dashboard:

- **Red tiles** indicate items requiring immediate action
- **Yellow tiles** indicate items approaching deadlines
- **Green tiles** indicate healthy status

### Step 2: Review Overdue Events

If the "Overdue Events" count is greater than zero:
1. Click the tile to filter the Calendar to overdue events only
2. Click the first overdue event to open its Event Workspace
3. Determine what is missing (steps, evidence, approval)
4. Take the required action or assign it to the appropriate person

### Step 3: Review Urgent Events

The **Urgent Events** panel on the left side of the dashboard lists events that need attention in priority order (most urgent first). For each event:
- The status badge shows its current audit state
- The due date shows how much time remains
- Click the event to open the full Event Workspace

### Step 4: Check My Tasks

The **My Tasks** panel shows your top 5 assigned tasks. To see all your tasks:
- Click "View All" to go to `/ces/my-tasks`
- Or open the Global Task Drawer from the top navigation bar

### Step 5: Review Recent Activity

The **Recent Activity** feed shows the most recent compliance actions across the organization. Use this to:
- Confirm that recent submissions were recorded
- Check if approvals are moving forward
- Identify any unusual activity

## Common User Actions

### I see an overdue event — what do I do?

1. Click the event to open the Event Workspace
2. Check which steps are incomplete
3. Complete outstanding steps
4. Upload missing evidence
5. Submit for approval if required

### I don't see any tasks assigned to me

- Check that you are logged in with the correct account
- Open the Global Task Drawer and verify the filter is set to "All"
- Contact your supervisor if tasks should be assigned to you

### The dashboard metrics look wrong

- Metrics are computed from live store data — if you recently completed work, try refreshing the page
- If metrics are still incorrect, contact your system administrator

## Expected Results

After daily dashboard review, you should:
- Know exactly which events need action today
- Have opened and begun any overdue items
- Have confirmed no new blockers have appeared overnight
