# End User Guide

## Step-by-Step System Usage
1. Sign in through the authentication flow.
2. Open Dashboard to review assignments, alerts, and execution status.
3. Navigate to My Tasks or workflow-linked pages for actionable items.
4. Open required forms, complete fields, and finalize signatures.
5. Confirm status updates and evidence registration before leaving the page.

## Common Workflows
- Task execution workflow: assignment -> completion -> verification.
- Event closure workflow: event review -> required actions -> closure evidence.
- Form signing workflow: open form -> complete -> sign -> lock evidence.

## Task Completion
- Validate requirements and due context.
- Complete all mandatory actions in the assigned page.
- Confirm task status and dependency resolution.

## Evidence Submission
- Submit required forms and approvals.
- Verify evidence appears in evidence/audit views.
- Ensure policy_id, workflow_id, and event_id context is retained for traceability.
