# M01 Learning Objective Traceability Matrix

## Learning Objectives

- **LO1:** Define cultural competence and CLAS-linked care expectations.
- **LO2:** Identify cultural factors impacting care communication.
- **LO3:** Apply language access/interpreter and communication workflows.
- **LO4:** Recognize/report discrimination and retaliation concerns.
- **LO5:** Demonstrate respectful, patient-centered, professionally documented care.

## Objective Completion Criteria

- Learner must pass final assessment at >=80%.
- Learner must complete all debriefs.
- Any missed high-risk item (documentation/escalation/interpreter) requires remediation completion before module close.

## Traceability Status

All learning objectives are represented in narrative, challenge decisions, debrief reinforcement, and final assessment validation.
