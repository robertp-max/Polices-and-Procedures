## Branching Consequence Design

- Wrong choices trigger realistic consequences:
  - patient misunderstanding
  - refusal risk
  - delayed escalation
  - documentation exposure
  - survey-risk narrative flag
- Every wrong branch includes:
  - what happened
  - why it is unsafe/noncompliant
  - exactly how to correct workflow

## Wrong-Answer Design Rule (Locked)

- No obvious throwaway distractors.
- All options must sound initially plausible to a working clinician.
- Incorrect options must fail for nuanced reasons:
  - incomplete sequencing
  - weak documentation defensibility
  - delayed/insufficient escalation
  - weak interpreter-language workflow
  - weak patient-centered communication
  - weak closed-loop coordination
  - weak risk mitigation

## Mandatory Debrief Components (Each Challenge, Locked)

1. Correct answer and rationale
2. Why each incorrect answer appears tempting
3. Why each incorrect answer ultimately fails
4. Compliance reference (policy + ACHC concept)
5. Documentation requirement and record-quality implications
6. Escalation path and timing implications
7. Patient safety impact
8. ACHC/CMS survey defensibility concern
9. Workflow breakdown pattern that caused the error
10. Real-practice coaching point for future field decisions

## Remediation Logic

- If learner misses any challenge:
  - immediate debrief is shown
  - one remediation mini-scenario appears before progression
  - remediation attempt is logged for LMS defensibility tracking

## Character-Driven Teaching Requirement

Each challenge and debrief should be delivered through character interactions where possible:

- Marites asks operational questions
- mentor explains workflow reasoning
- rushed coworker illustrates shortcut failure
- supervisor links behavior to accountability, safety, and defensibility
