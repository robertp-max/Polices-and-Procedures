## Learner-friendly policy language

Employee cards use assignment language—Read, Read + acknowledge, Read + quiz, Awareness only, or No employee action. Internal `Partial hold`, `Hold`, `Owner release required`, and `source conflicts` language is absent from employee mode.

## Unavailable content

An assignment without approved learner content is disabled and states:

- `Content not yet available`
- `No employee action required`

It is not presented as an available module.
